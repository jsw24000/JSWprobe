# Invariant And Equivariant Smoke Experiments

This directory evaluates frozen DINOv2 official and VGGT representations on the controlled object-translation dataset generated by `memory_scene_blender`.

The code is intentionally low-intrusion:

- DINOv2, VGGT, and Blender dataset outputs are read-only inputs.
- No model weights are copied.
- No weights are downloaded.
- All hooks, pooling, probes, and analysis code live here.
- Adapter training is not implemented in v1; only the interface placeholder is reserved.

## Environment

Smoke was designed for the existing conda environment:

```bash
conda activate vggt
```

No extra packages were installed for the smoke pipeline.

## One-Step Smoke

From this directory:

```bash
bash scripts/run_smoke_pipeline.sh
```

Force recomputation:

```bash
bash scripts/run_smoke_pipeline.sh --force
```

## Step-By-Step

```bash
python scripts/audit_dataset.py --config configs/smoke.yaml
python scripts/inspect_models.py --config configs/smoke.yaml
python scripts/extract_features.py --config configs/smoke.yaml --model dinov2
python scripts/extract_features.py --config configs/smoke.yaml --model vggt
python scripts/run_absolute_position.py --config configs/smoke.yaml
python scripts/run_delta_decode.py --config configs/smoke.yaml
python scripts/run_forward_equivariance.py --config configs/smoke.yaml
python scripts/run_homogeneity.py --config configs/smoke.yaml
python scripts/run_subspace_analysis.py --config configs/smoke.yaml
python scripts/run_intervention.py --config configs/smoke.yaml
python scripts/run_composition.py --config configs/smoke.yaml
python scripts/build_report.py --run-dir outputs/smoke_v1
```

## Full Experiment Command

The full config is prepared but not run by this task:

```bash
bash scripts/run_full_pipeline.sh
```

## Smoke Subset

The default smoke run uses scene-level splits:

- train: `scene_000`, `scene_001`
- validation: `scene_002`
- test: `scene_003`

Each scene uses a `3x3` position subset and cameras `camera_000`, `camera_003`, `camera_006`, `camera_009`.
